# Midnight Vice

Midnight Vice turns photos into neon-noir GTA 6-style cover art — multi-panel posters, striped chrome titles, role tags, PNG export in 3 sizes, fully offline.

## Run

1. `node serve.ts` — serves app on http://localhost:8080
2. Open http://localhost:8080 in a browser
3. Upload 1–7 photos, choose a layout, apply grades, edit titles/tags, export PNG
